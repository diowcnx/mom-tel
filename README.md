# mom-tel 📱

แอปพลิเคชันโทรศัพท์ Android สำหรับผู้สูงอายุ (Elderly-Friendly Phone Dialer) ใช้งานง่าย ตัวหนังสือใหญ่ ปุ่มชัดเจน และปลอดภัย

## คุณสมบัติเด่น (Key Features)

- 📇 **สมุดโทรศัพท์ 6 ช่องใหญ่:** จัดวางแบบ 2 คอลัมน์ x 3 แถว พร้อมรูปภาพขนาดใหญ่และชื่อตัวอักษรชัดเจน (Prompt Font)
- 🔍 **ระบบค้นหารายชื่อ:** ค้นหาได้ทั้งจากชื่อหรือเบอร์โทรศัพท์ พร้อมแสดงผลในรูปแบบลิสต์ที่อ่านง่าย
- ↩️ **กด "สมุดโทรศัพท์" กลับหน้าแรก:** แตะที่หัวข้อหรือปุ่มย้อนกลับเพื่อล้างการค้นหาและกลับสู่หน้าแรกทันที
- 📞 **หน้ารับสายและโทรเข้า-ออกขนาดใหญ่:** ปุ่มรับสาย (สีเขียว) และปุ่มปฏิเสธสาย (สีแดง) ชัดเจน ไม่กดพลาด
- 🔢 **แป้นกดเบอร์ขนาดใหญ่ (Dialpad):** แป้นสี่เหลี่ยมโค้งมน ตัวเลขชัด ปุ่มเครื่องหมาย `*` และ `#` สมดุลและอยู่กึ่งกลาง
- ✏️ **แก้ไขรายชื่อและเปลี่ยนรูปภาพได้ง่าย:** แยกช่อง "ชื่อ" และ "นามสกุล" ปรับปรุงข้อมูลลงในฐานข้อมูลผู้ติดต่อของเครื่องอย่างแม่นยำ

## การติดตั้งและใช้งาน

1. โคลนโปรเจกต์:
   ```bash
   git clone https://github.com/diowcnx/mom-tel.git
   ```
2. เปิดโปรเจกต์ด้วย Android Studio หรือคอมไพล์ผ่าน Gradle:
   ```bash
   ./gradlew assembleDebug
   ```
3. ติดตั้งลงเครื่อง Android ผ่าน ADB:
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
