# mom-tel — สถานะงาน

อัปเดตล่าสุด: 21 พ.ย. 2026

## ทำอะไรไปแล้ว (ล่าสุด)
- หน้าแป้นกดตัวเลข: เปลี่ยนลูกศรย้อนกลับเล็ก ๆ มุมซ้ายบน เป็นปุ่ม "กลับหน้าหลัก" ใหญ่เต็มความกว้าง (สูง 68dp สีเหลืองอ่อนขอบส้ม)
  วางไว้ด้านบน ไกลจากปุ่มโทรสีเขียว เพื่อไม่ให้แม่กดพลาด และเอาหัวข้อ "กดเบอร์โทรศัพท์" ออกเพื่อไม่ให้แป้นตัวเลขเล็กลง

## ค้าง / ติดอะไร
- **ยังไม่ได้ build และยังไม่ได้ลงมือถือแม่** — แก้บนเครื่องที่ไม่มี Java/Android Studio
  ต้อง build + ติดตั้งบนเครื่องที่มี Android Studio แล้วลองกดจริง

## งานถัดไป
1. บนเครื่องที่มี Android Studio: `git pull` → `./gradlew assembleDebug testDebugUnitTest` → `adb install -r app/build/outputs/apk/debug/app-debug.apk`
2. ลองบนมือถือแม่: ปุ่มกลับหน้าหลักกดง่ายไหม แป้นตัวเลขยังใหญ่พอไหม (ทดสอบโทรด้วยเบอร์ 0984914245 เท่านั้น ตาม AGENTS.md)

## กับดักที่เจอมาแล้ว
- เครื่อง Mac ที่ใช้โฟลเดอร์ `/Volumes/GB512/ai/mom-tel` ไม่มี Java runtime — `./gradlew` รันไม่ได้

## ตั้งเครื่องใหม่
- ติดตั้ง Android Studio (มี JDK ในตัว) + Android SDK, เปิดโฟลเดอร์โปรเจกต์, เปิด USB debugging บนมือถือ
- ไม่มีไฟล์ลับหรือ `.env` ที่ต้องคัดลอกตามไป
